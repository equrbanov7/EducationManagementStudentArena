## 1. Bir abzasda vəziyyət

Qərbi Kaspi Universitetinin köhnə MyEdu sistemi (MariaDB, 2.14 GB, 81 cədvəl,
9,044,531 sətir) yeni EMS Arena Django sisteminə köçürülür. Köçürmə **birbaşa
SQL kopyası deyil** — hər sətir audited kontraktdan keçir, qərarı append-only
ledger-ə möhürlənir və eyni mənbədən eyni nəticə bayt-bəbayt təkrarlanır
(`determinism_digest`). Hazırda 17 faza kodlanıb və lokal repetisiya bazasında
işləyir. Sonrakı addım real serverə birdəfəlik keçiddir.

## 3. Son iki günün qərarları və SƏBƏBLƏRİ

Bunlar texniki zövq məsələsi deyil — hər biri ölçülmüş problemə cavabdır.

### 3.1 Qrup-başına jurnal bölgüsü
**Problem:** bir köhnə jurnal bütün qrupları birləşdirirdi; nəticədə UI-da
61 MB-lıq HTML səhifələr yaranırdı (>5000 xanalı 46 jurnal).
**Qərar (sahibin):** «hər qrupun əslində bir jurnalı olsun».
**Nəticə:** >5000 xanalı jurnal 46 → 8. Qalan 8-i bir köhnə fənnin birləşmə
klasteridir və UI səhifələmə tələb edir (backlog).
**Təsir:** bir jurnal `uniqid` çoxlu `CourseOffering`-ə açılır — hədəfdə
açılış sayının mənbə jurnal sayından çox olması **gözləniləndir**.

### 3.2 Arxiv üzvlüyü (məzun/qeyri-aktiv tələbələr)
**Problem:** mənbənin ~30 %-i köçmürdü — 2,603 qeyri-aktiv tələbə.
**Qərar:** məzunlar silinmir, «arxiv üzvlüyü» ilə köçür.
**Nəticə:** +49,540 qeydiyyat açıldı. Qəbul ili tapılmayanlar üçün
`ARCHIVE_FALLBACK_ADMISSION_YEAR = 1950` sentineli.

### 3.3 J5b — tarixi giriş balı arxiv komponenti
**Problem:** tələbələrin 16.2 %-i səhvən «kəsilmiş» görünürdü.
**Kök səbəb:** data düzgün köçmüşdü, **hesablama** fərqlənirdi (köhnə sistemin
düsturu ilə tətbiq etdikdə 89.8 % ±2 uyğunluq).
**Qərar (sahibin):** «köhnə datanı silmə, pozma, dəyişmə — hər necə
hesablanıbsa hesablanıbdır».
**Həll:** köhnə giriş balı GENERIC komponent kimi **qalıq** şəklində saxlanılır
(`residual = clamp(girish − Σkollokvium − checklist, 0, 50)`), çünki
`entry_score_for` kollokviumu onsuz da üstünə gəlir.
**Simulyasiya:** kəsr 742 → 287, kredit 5,729 → 7,835, ÜOMG 56.71 → 64.57.

### 3.4 «Qiymətləndirilməyib» statusu
106,870 yazılışın 23,382-si nə keçmiş, nə kəsilmişdi — heç bir qutuya
düşmürdü və rəqəmlər səssizcə itirdi. İndi ayrıca sayılır ki, imtahan mərkəzi
icazə ilə onları doldura bilsin.

### 3.5 Jurnalda təsdiq zənciri LƏĞV EDİLDİ
**Sahibin sözü:** «jurnal təsdiqə getməyi yoxdu, elə olmur bu — müəllim balı
yazır və bitir». Əvəzinə **RİM semestr sonunda fakültə-fakültə jurnalları
bağlayır**; bildiriş imtahan mərkəzinin kollokvium marşrutu ilə eyni dizayndadır.

### 3.6 İmtahan balını yalnız İmtahan Mərkəzi yazır
Yazılı və praktiki imtahanlar kağız üzərində/kodda keçir. Ona görə balı sistemə
İmtahan Mərkəzi əl ilə daxil edir (qrup seç → bir-bir yaz → şəkil/mətn əlavə et).
İcazə qəsdən `final_score.entry` adlanır — `exam.*` wildcard-ı onu ÖRTMƏSİN deyə.
Bal tam ədəddir; **dəyişmək olar, silmək olmaz**.

### 3.7 Sənədsiz dəyişiklik qadağandır
**Sahibin sözü:** «təqdimatsız heç nəyi dəyişmək olmasın». Jurnal və imtahan
nəticəsi ilə bağlı kritik dəyişikliklərdə **təqdimat (sənəd) yüklənməsi
məcburidir** — audited correction axını PDF + sarı işarə + tarixçə ilə.

### 3.8 RİM = İKT Rəhbəri
Ayrıca rol yaradılmadı. **Mövcud `ikt_rehber` rolu RİM-dir, yalnız görünən adı
dəyişdi.** Rəqəmsal İnkişaf Mərkəzi əsasnaməsi əsasında səlahiyyətləri var:
parol sıfırlama, ad/soyad/**ata adı** üzrə istifadəçi axtarışı, bloklama,
soft-delete, məlumat yeniləmə, icazə vermə.

### 3.9 Transkript tələbədən gizlədildi
`registrar.public.STUDENT_TRANSCRIPT_SELF_SERVICE = False` — **tək bayraq iki
qapını** idarə edir: bölmə siyahısı (birbaşa URL də bağlıdır) və PDF endpoint-i
(404). Əməkdaş yolu toxunulmayıb. Müraciət (ərizə) pəncərəsi qurulanda açılacaq.

## 4.4 Köhnə giriş balı düsturu — datadan çıxarıldı

Sahib rəsmi düsturu verməmişdən əvvəl onu datanın özündən geri-mühəndislik
yolu ilə tapdıq (müstəqil çarpaz-yoxlama olsun deyə):

```
giriş = ROUND(davamiyyət + sərbəst_iş + seminar)          maksimum 50
  davamiyyət = 10 × (N − Q) / N        0…10   (N = xana sayı, Q = «qb» sayı)
  sərbəst_iş = «si» xanası             0…10
  seminar    = 3 × ORTA(k1,k2,k3 + gündəlik qiymətlər)    0…30
```

Sahibin dediyi «qayıb cədvəli» **sayla yox, FAİZLƏ** pillələnir: ≤5 % → 10 bal,
5-15 % → 9, 15-25 % → 8, hər 10 faiz bəndinə bir bal. Kəsr şərti `Q/N > 25 %`.
Güzəşt (`guzest_*`) girişə daxil deyil; üzrlü qayıb təsirsizdir.

**Sübut gücü:** `balvereqi_logs` cədvəlində köhnə sistemin ÇAP OLUNMUŞ bal
vərəqləri saxlanılır — 903,943 tələbə sətri. Düstur orada **97.24 % dəqiq,
100 % ±1** uyğunlaşır və 2023-2026 boyu sabitdir.

Detal: `docs/migration/LEGACY_GIRISH_FORMULA.md`, referans implementasiya
`legacy_girish_reference.py`.

## 4.5 ⚠️ Köhnə və yeni modelin ÜÇ STRUKTUR FƏRQİ

Düsturu yeni sistemin `entry_score_for`-u ilə tutuşdurduqda üç fərq çıxdı:

| | Köhnə (MyEdu) | Yeni (EMS Arena) |
|---|---|---|
| **Davamiyyət** | 50 balın **10-u** davamiyyətdən | Bal vermir — yalnız qadağan mexanizmi |
| **Seminar/kollokvium** | `3 × ORTA(qiymətlər)` | Qiymətlərin **CƏMİ** |
| **Sərbəst iş** | `si` xanasının **BALI** (0-10) | Təhvil verilmiş mövzuların **SAYI** |

⚠️ **Bu, köçürülmüş tarixi ballara TƏSİR ETMİR** — J5b köhnə `girish` dəyərini
olduğu kimi arxiv komponenti kimi saxlayır (sahibin «hər necə hesablanıbsa
hesablanıbdır» tələbi). Fərq yalnız **yeni semestrlərdə** özünü göstərəcək.

Detal və sahibə verilən suallar: `docs/migration/GIRIS_BALI_MODEL_FERQI.md`.
