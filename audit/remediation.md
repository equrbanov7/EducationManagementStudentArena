## İlk mərhələnin yoxlamaları

Dəyişdirilən sahələr üzrə birləşdirilmiş PostgreSQL sınağında 343 test və 86 alt sınaq keçdi. Laboratoriya təhvilinə aid 5 JavaScript testi də keçdi. Django sistem yoxlaması xəta tapmadı. Modellərlə miqrasiyalar arasında fərq aşkarlanmadı. Yeni laboratoriya miqrasiyası ayrıca lokal bazada tətbiq edildi, geri qaytarıldı və təkrar tətbiq edildi.

Modul ölçüsü, modulların asılılıqları, açıq proqramlaşdırma interfeysləri və tərcümə kataloqları üzrə yoxlamalar keçdi. Dəyişdirilən 42 Python faylı, eləcə də layihənin Git-də izlənən Python mənbələrinin və yeni məhsul kodunun ayrıca nüsxəsi Black, isort və Flake8 yoxlamalarından keçdi. Bütün lokal qovluq yoxlananda əvvəlcədən mövcud olan `tools/tutorials/` və `tmp/pdfs/` fayllarında format və lint xətaları qalır.

### İkinci mərhələnin yekun yoxlamaları

- **PostgreSQL.** Laboratoriyalar, əlaqə, fənn qovluğu, bildirişlər, kurslar, təşkilatlar, qrup əməliyyatları, imtahan bağlantıları və infrastruktur üzrə birləşdirilmiş sınaqda **1 380 test keçdi**. Dörd paralel test icraçısı istifadə edildi. C və Azərbaycan ICU lokallarında ayrıca boş bazaların hər birinə 471 miqrasiya tətbiq edildi.
- **Brauzer və JavaScript.** Kurs və qrup axınlarının Chrome paketində **9/9**, layihənin JavaScript paketində **584/584** test keçdi. Əlavə Chrome sınaqlarında iki akademik əməliyyat və əlaqə, filtrlər, admin formaları üzrə 17 müşahidə yoxlanıldı. Müxtəlif test paketlərinin sayları ayrıca verilib.
- **İcraçı və anbar.** Bildirişlər üçün ayrıca Celery prosesi və məhdud PostgreSQL rolu, imtahan bağlantıları üçün Redis və Channels işlədildi. Mobil push provayderi sintetik idi. Bərpa sınağının Restic nüsxəsi `bbf7ebde64bd` ilə başlayır. Baza nüsxəsinin SHA-256 dəyəri `c99022fd19fb3adbc13c8bfaf5601f556632e41819f6f7cbd6520b71659bdfb2`, qoşmanın dəyəri `721b492516f87cb2fa1d08b8667adcc4614b37a9f2c98ffd80a67ef2a37abdd0` oldu. Sınaq bitəndə bərpa skriptinin yaratdığı müvəqqəti bazaların sayı sıfır idi.
- **Kod və konfiqurasiya.** Django sistem yoxlaması, miqrasiya uyğunluğu, modul ölçüsü və asılılıqları, tərcümə kataloqları, hər iki dəyişən GitHub Actions faylının sintaksisi və `scripts/deps/lock.sh --check` keçdi. Git-in izlədiyi Python mənbələri və düzəlişlərə daxil edilən yeni fayllar Black, isort və Flake8 yoxlamalarından keçdi. İşçi qovluğun hamısı üzrə əvvəlcədən mövcud dörd kənar fayl `tools/tutorials/` və `tmp/pdfs/` altında format və lint xətaları verir.

İstehsalat məlumatları və əvvəlki tarixi tələbə qeydləri bu mərhələlərin əhatəsindən kənardadır. Düzəlişlərin nəticələri lokal, sintetik mühitdə ölçülüb.
